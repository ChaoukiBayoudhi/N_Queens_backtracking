# N-Queens backtracking

A backtracking solution for N-Queens problem.

## Tech stack

- Java (no build tool: plain source files)

## Concepts covered

Collections, console input (Scanner).

## Project structure

- `src`: Application, NqueensBacktrackingProblem

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run `Application` (it contains the `main` method).
